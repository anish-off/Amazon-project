# Amazon Project

This project is a basic-level clone of Amazon, created to practice and test HTML, CSS, and JavaScript skills.

## About the Project

The goal of this project was to replicate the basic design and functionality of Amazon's homepage as a way to improve web development skills. It focuses on building the structure, styling, and basic interactivity of a webpage.

## Features

- Basic layout and design resembling Amazon's homepage.
- Styling implemented using CSS.
- Interactive elements powered by JavaScript.

## Technologies Used

- **HTML** - For the structure of the web pages.
- **CSS** - For styling and layout.
- **JavaScript** - For adding interactivity.
